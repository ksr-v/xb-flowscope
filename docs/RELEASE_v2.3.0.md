# FlowScope v2.3.0

## 更新

- 精简服务器管理命令，将下载、校验和清理逻辑放到当前面板提供的 HTTPS 管理入口。
- 交互式菜单：1 对接面板 / 升级；2 卸载采集器；0 退出。
- 安装清理已知旧程序缓存和临时残留，保留配置、采集身份、历史和待上报队列。
- 成功明确提示“安装成功，已完成对接配置”，首次数据仍需等待上报；失败明确提示安装失败。
- 卸载需输入 `UNINSTALL` 二次确认，清除本机程序、服务/drop-in/自启链接、配置、数据库、待上报流量及专用账号/组；面板历史不删除。

## 安装 / 升级

1. 下载 `flowscope-2.3.0.zip`，在 Xboard 插件管理上传升级并启用，**不要先卸载旧插件**。
2. 按部署方式重载常驻 PHP/Octane 工作进程并刷新后台。
3. 在「服务器管理 → 编辑服务器 → FlowScope」生成新管理命令，在对应服务器的 **Bash SSH 终端**执行。
4. 选择 1 对接或升级；需要卸载时选择 2，再输入 `UNINSTALL` 确认。

命令执行当前面板提供的 root Shell 脚本，仅信任自己的 HTTPS 面板。一次性对接凭证通过标准输入传递，10 分钟内有效，不放入 URL；菜单从终端单独读取。完整缓冲下载后才执行，失败或空下载不执行。面板管理入口须可访问。

## 卸载注意

本机数据库及未上报流量删除后无法恢复，除非自行备份。异常路径、挂载点、非专用账号或其他账号进程会拒绝继续。所谓清理范围是采集器自身安装资源；系统 journal、Shell 历史、操作员备份及测试 CA 不擦除，避免影响其他数据。取消卸载不删除数据。
