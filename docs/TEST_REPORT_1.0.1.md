# FlowScope 1.0.1 historical test report

Date: 2026-10-07 (Asia/Shanghai). All automated tests use workspace-owned fixtures. No live Xboard database, deployment or external checkout was modified by this development run.

Patch context: the user reported that 1.0.0 enabled successfully, `/status` reported enabled/supported, but JS/CSS requests returned 404. The same JS path with a trailing slash returned source. This identified a static-extension interception conflict in the deployment layer; the exact production proxy configuration was not accessed. Version 1.0.1 changes loader URLs to extensionless `script`/`style`, retaining fixed-file aliases, enable gating and response security headers. No schema migration or shared-file patch is added. The earlier missing-global result was not valid CSP evidence: the actual diagnostic omitted the globals' required double underscores.

PHP PDO SQLite/SQLite3/mbstring extensions were enabled per command from the existing PHP installation. Initial verification found and fixed a missing validation provider in the isolated harness, plain-HTML display-name rejection, incorrect initial hash-router/card selectors, Dashboard navigation-request races, stale-token response handling and quota unit-roundtrip precision. The 1.0.0 browser fixture did not exercise production static-suffix proxy handling; 1.0.1 fixes that compatibility gap and adds the proxy/injector pipeline regression. The recorded suites were rerun successfully after their relevant fixes. No unresolved failure is being reported as a pass.

Browser evidence: `tests/.runtime/ui/browser-results.json` and screenshots `dashboard-light-desktop.png`, `dashboard-dark-desktop.png`, `dashboard-dark-mobile.png`, `native-editor-desktop.png`, `native-editor-mobile.png`. Images show actual Admin layout and plugin UI, not generated mockups. Native rank/queue content in the browser fixture is not production telemetry.

Reproduction: on Windows use `scripts/test.ps1`, which enables existing PHP extensions for this process. On Linux install/enable PDO SQLite and mbstring normally, set `XBOARD_PATH`, and run `sh scripts/test.sh` (the Linux script itself was NOT RUN in this Windows environment). For browser verification set `FLOWSCOPE_ADMIN_DIR` and `FLOWSCOPE_BROWSER` as described in README, then run `node tests/ui-browser.mjs`. Package with `php scripts/package.php` (zip extension required), then run `php tests/package.php` with the test extensions. See README for the build lock and upstream daily-statistics/legacy/UDP limitations.
