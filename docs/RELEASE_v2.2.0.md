# FlowScope v2.2.0

Xboard 独立扩展：物理服务器网卡周期流量、采集器一键安装、出口 IPv4 展示。

## 更新

- 服务器管理：在最后心跳、节点数下展示出口 IPv4。由采集器查询 IP.SB 的 HTTPS IPv4 专用接口，不向第三方传输服务器 Token。
- 仪表盘周期流量改为桌面四列、平板两列、手机一列。
- 短期单次凭证一键安装，自动启动及开机自启；修复默认 Python User-Agent 被拦截的问题。
- 兼容空白安装和旧版原位升级，保留配置、采集身份、数据库和积压上报。孤立数据库、身份冲突、异常软链接或权限异常时停止，不自动删除数据。

## 安装 / 升级

1. 下载 `flowscope-2.2.0.zip`，在 Xboard 插件管理上传安装或升级并启用。已有版本不要先卸载。
2. 按部署方式重载常驻 PHP/Octane 工作进程并刷新后台。
3. 进入「服务器管理 → 编辑服务器 → FlowScope」，生成命令，在对应 Linux 宿主机执行。
4. 旧采集器执行新命令原位升级后才会上报 IPv4；旧版仍兼容原有流量采集。

面板需要有效 HTTPS；采集端需要 Linux、Python 3.9+、systemd 和 curl 等工具。已审计 Admin 构建为 `index-CEIYH7i8.js`，不保证其他构建兼容。仅统计安装后已采样的网卡增量，不回填之前整月流量，不保证断电前未采样尾段零丢失。
